关于"接入账号自动发布"的可行性结论

结论：全自动发布不可行也不建议做；已用"发布辅助闭环"替代。

1. 官方 API 路线：抖音/小红书/视频号的视频发布能力仅对企业资质开放且需平台审核，个人创作者拿不到授权；B站虽有个 人投稿 API 但需 OAuth 接入与密钥管理，超出本地 HTML 工具的安全边界。各家接口还会随版本频繁变动。
2. 浏览器自动化路线（模拟点击上传页）：违反各平台用户协议，触发风控会导致限流甚至封号——用的是你自己的真实账号，风险不可逆。
3. PRD 既定边界：PRD-00 §4 明确"向平台自动发布"为 Out of Scope，D-06 决策「标记已发布只写本地状态，绝不调用平台」，NFR-06 为合规红线。

已实现的替代闭环（本轮）：排期定时间定账号 → 一键复制标题/标签/全文 → 直达对应平台创作者后台 → 手动发布 → 回来一键标记（自动生成各账号待回填记录）。把每次发布的手工操作压缩到 1 分钟内，且零封号风险。
未来可选：若你后续有企业资质，可在设置里加"开放平台适配器"预留位（填自己的 API 凭证），属于 v2.0 议题。
