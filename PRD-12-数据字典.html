PRD-12 · 数据字典（DD-*）

持久化为单一 JSON（localStorage 单键），顶层结构： {version, studio, ips[], accounts[], contents[], topics[], hots[], benches[], posts[], ai, std, settings}。字段类型记法：s=字符串, n=数字, b=布尔, []=数组, {}=对象。

DD-IP

字段类型说明/约束
idsuid，主键
name / track / persona / audiences名称(必填)/赛道/人设一句话/目标观众
weeklyGoaln每周更新目标条数，默认 3
color / avatars主题色索引(0–7) / 形象索引(0–7)
createdAtn时间戳

DD-ACCOUNT

字段类型说明/约束
id / ipIds主键 / 所属 IP（外键，级联见 FR-01-07）
plat / names平台 key / 账号名；(ipId,plat,name) 唯一
fans / fansGain7dn登记粉丝数 / 近 7 日涨粉（手动）
links主页链接，可空

DD-CONTENT

字段类型说明/约束
id / ipId / topicId?s主键 / 归属（可为 null=未归属）/ 溯源选题
stages枚举 topic|script|shoot|schedule|published（单向推进，允许跳过无分镜直接排期）
title / hook / body / cta / covers标题 / 开头钩子 / 正文(多行) / 结尾引导 / 封面大字
tags[]s标签数组
shootDate / shootDone / editDones/b/b拍摄日(yyyy-mm-dd) / 拍完 / 剪完
planAt / targetAccIdss/[]s计划发布时间(ISO 本地) / 目标账号 id 列表
shots[]DD-SHOT分镜
snaps[]存稿快照 {at, title, hook, body, cta, cover, tags}，≤20，FIFO
createdAt / updatedAtn时间戳

DD-TOPIC

字段类型说明/约束
id / ipIds主键 / 归属
titles必填
sources枚举 manual|hot|bench；srcRef 存热点/对标回链 id
sc{}五维 {pain, util, hype, susp, fit} 各 1–5
statuss枚举 pool|doing|done

DD-HOT

字段类型说明/约束
id / titles主键 / 标题(必填)
ips[]s适用 IP id 列表（空=仅全部视图）
src / heat / trend / notes来源 / 高中低 / 升平降 / 备注
createdAt / dueAtn创建时间 / 到期=创建+72h
angles{}{ipId: [角度句×3]}；AI 增强后同结构覆盖
converted[]s已转选题 id 列表

DD-BENCH

字段类型说明/约束
id / ipId?s主键 / 归属 IP，null=全部共用
plat / name / fanss/s/n平台 / 账号名 / 粉丝量
tiers枚举 peer|higher|top（同量级/高一级/头部标杆）
criteria[]b6 条选择标准勾选
works[]DD-WORK作品拆解列表

DD-WORK（对标作品）

字段类型说明/约束
id / titles主键 / 标题
likes / cmts / favs / sharesn互动数据（DD-NUMPARSE 解析）
scripts整段口播稿原文
seg{}{hook, body, cta} 三段文本（自动拆后可改）
angle / hookT / struct / endTs四类标签（PRD-03 §3.2 词表 key，空=未归类）；locked 标记人工改过不再自动覆盖

DD-POST（发布记录 · 复盘最小单元）

字段类型说明/约束
id / contentId / accIds主键 / 内容 / 账号；(contentId,accId) 唯一
publishedAts实际发布时间（标记时默认 planAt）
actualSecn实际成片时长（秒）
play / five / avgSecn播放 / 5 秒完播(%) / 均播(秒)；可空
like / cmt / fav / share / gainn赞/评/藏/转/涨粉；可空

DD-NUMPARSE（数字解析规则）

  • 输入容忍：1.2万 1,234 3.5w 120 空；输出数字或 null。
  • 规则：去逗号与空白；「万 / w / W」×10000；「亿」×100000000；纯数字直取（支持小数）；无法解析 → null 并标红（FR-03-02 / FR-08-01）。

DD-SETTINGS / DD-STD

字段默认说明
std.wpm240口播语速 字/分
std.fiveLine / favLine / avgLine / cmtLine60 / 2.2 / 40 / 0.5完播% / 收藏率% / 均播比% / 评论率%
std.hotMult / favRatio2 / 0.5爆款倍数 / 收藏型画像比
std.gradeS/A/B21 / 17 / 13选题评级线（总分 25）
std.coverMax / ipLimit12 / 8封面字数上限 / IP 上限
settings.themelightlight / dark
settings.plats内置 8平台清单（可自定义追加）
settings.nodes内置+自定义营销节点 {name, date, builtin}
settings.banned自建词库极限词/收益承诺词表（可增删）
ai.{provider,base,key,model,temp,chats[]}未配置key 导出时剥离（FR-10-05）
