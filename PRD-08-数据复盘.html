PRD-08 · 数据复盘

回答"流量掉在哪"。一行 = 一条内容 × 一个账号，手动回填（支持粘贴增强），四象限诊断 + 趋势 + 对比 + 自动周报。

1 · 用户故事

  • 昨晚发了 3 个号 → 从平台后台把数字抄过来（或直接粘贴）→ 立刻知道哪条开头不行、哪条可以做成系列。
  • 周五看周报 → 本周比上周涨了还是跌了、最佳最差是谁、下一步做什么。

2 · 功能需求

编号需求验收标准优先级
FR-08-01回填表格：每行（内容×账号）字段——实际时长/播放/5 秒完播%/均播秒/赞/评/藏/转/涨粉；「1.2万」缩写解析（DD-NUMPARSE）；逐行保存数字解析失败标红；留空合法（如平台无该指标）P0
FR-08-02粘贴回填：从剪贴板粘贴一列/一行数字自动按当前列或行填充（支持夹杂「万」缩写与空值）→ Q-04粘贴前预览解析结果，确认后写入P1
FR-08-03五项总览卡：发布数 / 总播放 / 平均播放 / 平均 5 秒完播 / 总涨粉（按当前 IP 过滤与日期范围）与表格数据实时一致P0
FR-08-04单条诊断：按 §3 象限规则输出结论标签 + 逐指标解读行（达标绿/未达红/无数据灰，各带一句建议）无 5 秒完播的平台自动跳过该项并说明P0
FR-08-05象限散点图：x=5 秒完播，y=收藏率，参考线=设置阈值；点按 IP 着色、点大小=播放；点击点看单条诊断SVG 手绘；空数据占位P1
FR-08-06趋势折线：按发布日期的播放与收藏双轴（或切换）；可按 IP/账号筛选最近 30 天默认窗口，可扩P1
FR-08-07对比视图：「按 IP」或「按账号」的条形对比——发布量/总播放/平均播放/5 秒完播/收藏率/评论率/涨粉（指标切换）指标切换即时重绘；含均值参考线P1
FR-08-08筛选器：日期范围 / 平台 / IP / 账号；全部图表与总览受筛选联动筛选条件显示为可清除的 chipsP0
FR-08-09自动周报：近 7 天 vs 上一周期——发布数、播放、涨粉变化（升/降%）、最佳单条与最差单条（引用诊断结论文本）；导出 Word 与 Markdown（→ Q-04）周报为只读生成物，不含 Key 与敏感配置P0
FR-08-10删除发布记录：单独删除某行（二次确认，提示连带清理图表口径）删后各视图立即重算P0

3 · 诊断规则（象限，原创转写）

指标口径：收藏率 = 藏/播放；评论率 = 评/播放；均播比 = 均播/实际时长；参考线取设置（Q-06）：5 秒完播 fiveLine=60%、收藏率 favLine=2.2%、均播比 avgLine=40%、评论率参考 0.5%。

5 秒完播收藏率结论建议方向（原创文案）
✓ 达标✓ 达标爆款潜质（绿）同结构做系列；若播放 < 该账号历史平均 ×60%，提示检查发布时段/标签
✗✓内容好 · 开头弱（黄）结果/冲突提到前 5 秒，删铺垫与自我介绍
✓✗开头强 · 干货弱（黄）加清单、步骤、可直接照做的模板
✗✗需要重做（红）回到选题五维重新评估该赛道选题
平台无 5 秒完播指标时：仅按收藏率评 绿(收藏达标)/黄(收藏偏低)，并注明"此平台看收藏与互动"。
  • 逐指标解读行：5 秒完播 → 推流速度；均播比 → 推流长度（中段悬念）；收藏率 → 实用性（清单化）；评论率 → 互动引导（二选一提问）。
