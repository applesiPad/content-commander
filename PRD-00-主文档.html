1 · 产品概述

把一条口播内容的完整生命周期——热点 → 对标拆解 → 选题 → 写稿 → 拍摄/提词 → 排期 → 复盘——装进一个浏览器工具。单文件 HTML、双击即用、数据存本机、AI 可选接入。按「IP（人设）→ 账号（IP×平台）→ 内容 → 发布记录（内容×账号）」四层组织数据，支持一稿多发、分账号回填与对比。

项内容
暂定名多号创作台（占位）。候选：口播创作站 / 内容指挥部 / 创作多面体 → Q-01
形态单文件 HTML（内联 CSS/JS，零依赖、零构建、离线可用）
平台PC 桌面浏览器（Chrome / Edge 近两年版本）
数据localStorage 单键 JSON + 版本化迁移；禁用时降级内存并显著警告
参照物功能对齐 workstation-media（开源版）全模块；实现完全原创，开发过程不接触参照源码

2 · 目标用户与核心场景

画像描述典型一天
多 IP 主理人（主）同做 2–8 个人设，每人在 1–3 个平台开号，每周产出 3–10 条口播早上扫热点定选题 → 下午写稿体检 → 晚上拍摄提词 → 排期后回填昨天数据
单号新手（次）只有一个号，需要方法论提示与判断标准拆一条对标爆款 → 套结构写第一篇 → 按体检改开头
小型工作室（延展）1 人主理 + 兼职剪辑，共用一台电脑用排期视图交接：主理人排期，剪辑看「拍完了」标记

3 · 产品目标与成功标准

  • 闭环完整：示例数据可在 10 分钟内走通「选题→写稿→分镜→排期→回填→诊断」全流程。
  • 无 AI 可用：不配置任何接口时，全部模块功能可用（AI 模板退化为提示词复制）。
  • 数据可靠：备份/恢复覆盖全部业务数据且不含 Key；schema 升级不丢数据（迁移链测试通过）。
  • 判断有据：每个模块的检查/评分/诊断都有可解释规则，且阈值可在设置中调整。

7 · 全局开放问题（核对清单）

Q-01 产品名称：暂用「多号创作台」占位，请定名或从候选挑一个。
Q-02 平台清单：默认 抖音/小红书/视频号/B站/快手/公众号/知乎/百家号 8 个（可自定义追加），是否增删？
Q-03 视觉：默认浅色 + 可切深色（深色为 P1）；主色蓝 #2563eb。确认或给偏好色。
Q-04 增强项取舍：粘贴回填 / 文案快照 / Markdown 周报 / IP 档案抽屉，哪些进 v1.0、哪些进 v1.1 或砍掉？
Q-05 评级阈值：选题总分 25 封顶，默认 S≥21 / A≥17 / B≥13 / C 其余。确认或调整。
Q-06 默认标准线：语速 240 字/分、5 秒完播 60%、收藏率 2.2%、均播/时长 40%、评论率 0.5%、爆款倍数 2、收藏型画像 0.5。确认或调整。
Q-07 AI 预设：服务商下拉含 DeepSeek/通义/GLM/豆包/Kimi/硅基流动/Ollama/自定义；默认选中「未配置」而非预填任何一家；预填模型名仅作参考展示。是否同意？
Q-08 原型保真度：本次原型为「结构 + 字段 + 流程」中保真（非最终视觉）。你核对布局与信息结构后，开发阶段视觉细节仍可微调。

9 · 术语表

术语定义
IP一个人设/内容品牌：名称、赛道、人设、目标观众、更新目标、形象与主题色
账号某 IP 在某平台登记的具体账号（仅资料登记，不登录不授权）
内容一条选题/稿件，含五段式文本与分镜，按阶段推进：选题→稿件→拍摄→排期→已发布
发布记录（post）一条内容 × 一个账号的一次发布及其回填数据，复盘的最小单位
五维选题评分五维度：痛点/实用/争议/悬念/赛道契合，各 1–5 分
评级按五维总分分 S/A/B/C 四档，决定优先级
体检对稿件的 10 项规则检查（见 PRD-05 §3）
分镜由稿件自动拆出的拍摄单元：景别/画面提示/台词/秒数/完成标记
象限诊断以 5 秒完播 × 收藏率两条参考线划分四象限给出单条结论
对标录入的他人账号及其作品拆解，用于借鉴角度与结构
