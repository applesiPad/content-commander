PRD-01 · IP 与账号

管理「人设层」与「账号层」：IP 的一切资料，以及各 IP 在各平台的账号登记。本模块是全产品的数据地基（见 PRD-12 DD-IP / DD-ACCOUNT），其余模块全部按 ipId 过滤（FR-01-06）。

1 · 用户故事

  • 作为多 IP 主理人，我要为每个人设维护独立的资料与账号矩阵，切换 IP 时看到的是"那一个人"的世界。
  • 作为主理人，我要一眼看出"哪个 IP 还没在哪个平台开号"（矩阵空位）。

2 · 功能需求

编号需求验收标准优先级
FR-01-01IP 新建/编辑/删除：名称、赛道、一句话人设、目标观众、每周更新目标（条/周）、主题色（8 色板）、形象（8 个自绘 SVG 头像之一）必填仅名称；每周目标默认 3；保存后 IP 卡片、切换器、拍摄/复盘过滤立即生效P0
FR-01-02IP 数量上限可配置，默认 8（设置项 ipLimit）达到上限时新建按钮禁用并提示"到上限，可在设置调整或删除不用的 IP"P1
FR-01-03账号登记/编辑/删除：归属 IP、平台、账号名、粉丝数、近 7 日涨粉、主页链接（可选）必填 IP+平台+账号名；同一 IP+平台+账号名组合不可重复P0
FR-01-04平台清单：默认 8 平台（抖音/小红书/视频号/B站/快手/公众号/知乎/百家号）+ 自定义追加（名称+颜色）→ Q-02自定义平台与内置平台在所有下拉/标签/矩阵中行为一致P0
FR-01-05矩阵覆盖表：行=IP、列=平台，格内显示粉丝数；空格显示「+ 开号」，点击直接打开账号表单并预填该 IP+平台行列随 IP/平台增删自动增减P1
FR-01-06全局 IP 切换器（顶栏常驻）：「全部 IP」或单个 IP；切换后热点/选题/文案/拍摄/排期/复盘/指挥板全部过滤选单 IP 时其他 IP 的内容在任何模块不可见不可编辑；刷新后记住选择P0
FR-01-07删除级联规则：删账号 → 同时删除该账号全部发布记录（posts）；删 IP → 其账号一并删除，其内容保留但标记「未归属」；两种删除均二次确认并提示"涉及 N 条发布记录，建议先备份"确认弹窗中明确列出将被级联删除的数量；操作可被取消P0
FR-01-08IP 档案抽屉：概况（账号、本周进度、累计发布）/ 内容列表（各阶段）/ 数据汇总（总播放、涨粉）→ 是否进 v1.0 见 Q-04从 IP 卡片点击展开；数据口径与复盘模块一致P2

3 · 规则说明

  • 「未归属」状态：内容的 ipId 指向已删除 IP 时显示灰色"未归属"，可在编辑中重新指定 IP，不参与 IP 过滤（只在「全部 IP」视图出现）。
  • 粉丝数口径：手动录入的登记值，不自动同步平台；近 7 日涨粉为手动登记的展示值。
  • 账号登记不登录、不授权、不验证任何平台（见 NFR-06、NFR-09）。
