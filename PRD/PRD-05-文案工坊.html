PRD-05 · 文案工坊

回答"稿子能不能拿去拍"。五段式分区写作、实时时长估算、10 项发布前体检、模板插入、存稿快照；写完一键进入拍摄并自动生成分镜。

1 · 用户故事

  • 写稿时我想知道"开头超没超 5 秒、信息点够不够、有没有踩极限词"，而不是拍完了才发现问题。
  • 改稿改崩了想退回上一版。

2 · 功能需求

编号需求验收标准优先级
FR-05-01内容记录：从选题立项（FR-04-07）或直接新建；归属 IP；五段式字段——开头钩子 / 正文（多行）/ 结尾引导 / 封面大字 / 标签（逗号或空格分隔）标题与开头为必填检查项（允许暂存不完整稿）P0
FR-05-02时长估算：全文 = 三段字数之和 ÷ 语速（字/秒，来自设置 wpm）；分段显示 开头/正文/结尾 各自秒数与总秒数输入即时重算；显示"约 X 分 X 秒"P0
FR-05-0310 项发布前体检（判定规则与影响面见 §3，全部原创实现）；得分 = 通过项/10×100，环形进度展示；每项显示 通过/未过 + 一句改法建议（原创文案）输入即时重检；未过项可展开看判定详情（如"现在 3.2 秒 / 标到 5.5 秒"）P0
FR-05-04极限词检测：全文比对自建词库（广告法禁用词类目：绝对化用语/夸大承诺/收益承诺等），命中处显示词与出现次数；词库可在设置中增删命中的体检项 10 未通过并给出位置提示P0
FR-05-05模板插入：钩子模板库与正文结构模板库（各 15+ 条原创文案），点击插入对应分区光标处模板可预览；插入不覆盖已有内容P1
FR-05-06套结构草稿（被 PRD-03 FR-03-08 调用）：按结构标签在五段预填原创占位提示（如"这里用数字抛结果…"）占位文字带特殊样式，可一键清除P1
FR-05-07存稿快照：每次显式保存压入历史（保留最近 20 版），可查看任一版本并与当前对比、一键回滚 → Q-04快照随内容记录存储并随备份走P1
FR-05-08「写完了，进入拍摄」：保存当前稿 → 自动生成初始分镜（规则见 PRD-06 §3）→ 拍摄日默认明天 → 目标账号默认该 IP 全部账号 → 跳转拍摄页已有分镜时提示"重建将覆盖手动编辑"并要求确认P0

3 · 体检规则表（10 项，原创判定）

#检查项判定规则影响指标
1开头 5 秒内说完开头字数 ÷ (wpm/60) ≤ 5.5 秒5 秒完播
2开头有结果或冲突开头命中钩子词表（数字、疑问、反差、结果前置词）推流速度
3标题埋痛点标题命中痛点词表（还在/焦虑/踩雷/不会/没时间/？等）点击
4实用信息点 ≥ 3正文按行统计"序号行"（第X/1./首先/其次/最后 等）≥ 3收藏
5中段埋悬念正文命中悬念引导词（最后/重点来了/先别划走/第三步…）均播
6带真实情绪经历全文命中第一人称经历词（我/当时/那天/熬/后悔…）共鸣
7结尾引导互动结尾非空且命中互动词（评论/你会/你觉得/扣/？/吗）评论率
8封面大字 ≤ 12 字封面去空白后字数 ≤ coverMax(12，可调)点击
9标签 3–5 个标签数 ∈ [3,5] 且含至少 1 个赛道词（赛道词=IP 赛道名或自定义词表）精准推流
10无极限词/收益承诺FR-05-04 检测零命中限流风险
词表在实现中集中定义（RULES 区），可维护、可扩充；体检为创作参考，不保证平台审核结果（NFR-09 声明）。
