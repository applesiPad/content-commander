PRD-03 · 对标拆解

回答"学谁、学他什么"。录入同行账号及其爆款作品，把整段口播稿自动拆成开头/正文/结尾，识别选题角度与结构套路，沉淀为可借用的规律，一键「借选题」「套结构」。

1 · 用户故事

  • 找到 3–5 个值得学的账号 → 每人贴 3–5 条爆款文案 → 系统告诉我他的开头套路、正文结构和最常用的组合。
  • 看到好结构 → 套进自己的新稿，占位提示留好，我只需要填自己的内容。

2 · 功能需求

编号需求验收标准优先级
FR-03-01对标账号录入/编辑/删除：归属（某 IP 或全部共用）、平台、账号名、粉丝量、三档定位（同量级/高一级/头部标杆）、6 条选择标准勾选≥4 条标准勾选时显示「好对标」徽章P0
FR-03-02作品录入：标题 + 点赞/评论/收藏/转发（支持「1.2万」式缩写，见 PRD-12 解析规则）+ 完整口播稿粘贴数字解析失败时标红提示手动改P0
FR-03-03自动分段：稿件切句后按启发式规则分到 开头/正文/结尾（规则见 §3.1）；三段均可手动改正并保存空稿不可拆；拆分结果持久化，重开页面不丢P0
FR-03-04结构识别：对三段识别 4 类标签（角度/开头钩子/正文结构/结尾方式，类目表见 §3.2）；每个标签可单击改为正确值识别不出时留空并提示"手动归类"；改过的标签不再被自动覆盖P1
FR-03-05爆款判定与画像：点赞 ≥ 中位数 × hotMult（默认 2）→ 爆款徽章；收藏/点赞 ≥ favRatio（默认 0.5）→ 收藏型画像标签阈值在设置中可调（D-04）；作品 <2 条时中位数不可用、不判定P0
FR-03-06规律小结：录满 2 条后统计各分类分布与平均点赞，输出"最常用开头→结构→结尾组合"小结卡随录入自动更新P1
FR-03-07借选题：从某条作品（或其角度标签）生成选题，预填标题与按标签映射的五维默认分，进入 PRD-04生成后回链可跳转查看P0
FR-03-08套结构写稿：按该作品的正文结构标签在 PRD-05 生成结构草稿（各分区留占位提示文字）草稿为全新内容记录，不复制对标原句；占位提示为原创文案P0

3 · 规则说明

3.1 自动分段启发式（原创转写）

  • 切句：按中英文句末标点（。！？!?\n）切句并保留标点。
  • 开头段：前 1–2 句中命中钩子词表（数字、疑问词、反差词、结果前置词）的句子；未命中则默认首句。
  • 结尾段：末 1–2 句中命中互动引导词表（关注/评论/点赞/收藏/你会/你觉得/二选一…）的句子；未命中则默认末句。
  • 其余全部归正文段。所有边界可手动调整。

3.2 结构标签类目（原创词表）

类别类目
选题角度（8）教程 / 避坑 / 测评 / 清单 / 故事 / 观点 / 对比 / 热点借势
开头钩子（8）提问式 / 数字式 / 反常识 / 结果前置 / 身份共鸣 / 悬念 / 警告 / 热点切入
正文结构（7）清单式 / 递进式 / 对比式 / 故事式 / 问答式 / 总分总 / 时间线
结尾方式（5）引导互动 / 总结升华 / 行动号召 / 反转 / 开放问题
识别规则基于关键词词表匹配，词表在实现中集中定义、可维护；识别结果定位为"参考，可修正"。
