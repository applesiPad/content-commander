PRD-09 · AI 助手

卡住时帮一把：16 个任务模板 + 自由对话，可带入 IP 档案/稿件/近 14 天数据。不配置接口时退化为"生成提示词，复制到外部 AI"，其余模块不受影响。

1 · 用户故事

  • 没配 Key：选「爆款标题×10」→ 带上我的 IP 档案生成一段提示词 → 复制到任意 AI 网页 → 结果贴回来手动用。
  • 配了 Key：直接在工作台里生成，标题一键加入选题池、开头一键替换进稿件。

2 · 功能需求

编号需求验收标准优先级
FR-09-01接口层：OpenAI 兼容 /chat/completions 与 Anthropic /messages 双协议；Base URL 由用户填写（自动拼路径，不重复后缀）；SSE 流式渲染；temperature 可调「测试连接」按钮返回成功/失败与可读错误（网络/跨域/Key 无效分类提示）P0
FR-09-02预设服务商：DeepSeek / 通义（百炼）/ 智谱 GLM / 豆包（方舟）/ Kimi / 硅基流动 / Ollama 本地 / 自定义；默认选中「未配置」；预填模型名仅展示参考并标注"以服务商控制台为准"（→ Q-07）Ollama 预设本地地址、Key 可空并提示本地跨域注意事项P0
FR-09-03上下文构建：可勾选带入——IP 档案（人设/赛道/观众）、指定稿件全文、最近 14 天 posts 汇总；带入项在发送前完整预览上下文组装为明文预览，用户可见即将发送的全部内容P0
FR-09-0416 个任务模板（提示词全部原创自写）：爆款标题×10 / 营销节点选题 / 热点角度 / 系列规划 / 对标拆解 / 打法总结 / 口播初稿 / 黄金 5 秒开头 / 分镜脚本 / 多平台改写 / 封面+标签 / 评论回复 / IP 定位 / 矩阵规划 / 周复盘 / 账号对比每个模板有说明与必选参数校验（如"周复盘"需有回填数据）P0
FR-09-05结果回填：指定模板的输出按格式标记解析后可——标题/选题 → 加入选题池；开头 → 替换稿件开头；全文 → 填入稿件；解析失败降级为手动复制回填前预览差异；原值可撤销一次P1
FR-09-06无 Key 模式：同模板生成完整提示词（含上下文）供复制；页面明示此模式不影响其他功能复制按钮一键复制全部提示词P0
FR-09-07对话管理：多会话列表、重命名/删除；对话历史随备份走；出错的消息可重试流式中断可停止；失败不写入历史P1
FR-09-08安全提示与 Key 处理：Key 仅存本机且不随备份导出（PRD-10）；对话页常驻"内容将发送到你配置的服务商"提示请求前校验 Base URL 为 http(s)P0
FR-09-09跨域失败引导：连接失败且特征符合 CORS 时，给出三条路径——换支持浏览器直连的服务商 / 用本地 Ollama / 自建中转（提供自写的中转说明文档，不随产品捆绑代理脚本）错误分类可读，不暴露原始堆栈P1

3 · 规则说明

  • 不捆绑代理脚本：只提供"如何自建中转"的原创说明文档（Nginx/Cloudflare Worker 两例，文档自写），避免分发可执行代理。
  • AI 生成内容一律标注"AI 生成，需人工核对事实与合规"；极限词检测（FR-05-04）同样适用于回填结果。
  • 模板提示词中固定注入创作底线：内容真实、不承诺收益、不贬低他人。
