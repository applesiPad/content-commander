PRD-10 · 设置 / 备份 / 引导

产品级配置入口、数据安全（备份/恢复/清空）与首次引导。所有阈值类设置集中于此（D-04）。

1 · 功能需求

编号需求验收标准优先级
FR-10-01欢迎向导（首次启动）：选主理人形象 → 填称呼与工作室名 → 二选一「载入示例工作室」/「从零开始」→ 完成跳过向导即视为从零开始；完成前不写业务数据P0
FR-10-02工作室设置：名称、主理人称呼与形象、主题（浅色/深色，→ Q-03）、IP 上限（FR-01-02）改动即时生效并持久化P0
FR-10-03数据标准：语速 wpm(240 字/分)；5 秒完播线 fiveLine(60%)；收藏率线 favLine(2.2%)；均播比线 avgLine(40%)；评论率线(0.5%)；爆款倍数 hotMult(2)；收藏型画像比 favRatio(0.5)；选题评级线 S/A/B(21/17/13)；封面字数上限(12)；IP 上限(8)；每项带"恢复默认"（→ Q-05/Q-06）任一改动即时作用于体检/评分/诊断相关模块；数值范围校验P0
FR-10-04AI 接口设置（FR-09-02 的 UI）：服务商下拉、Base URL、Key（密码框）、模型名、温度、测试连接；含"未配置"态Key 输入不明文回显；测试不发业务请求P0
FR-10-05备份导出：JSON 下载，包含全部业务数据与 AI 对话、示例/自定义平台/节点/词库，剥离 ai.key；文件带导出时间与 schema 版本导出文件不含任何 Key；导出前提示"含个人资料，妥善保管"P0
FR-10-06备份恢复：选择 JSON → 校验 schema 版本（不匹配走迁移链）→ 弹窗展示数量核对（IP/账号/内容/记录 N 条）→ 明示"覆盖而非合并" → 确认后恢复；恢复保留当前浏览器的 Key非法文件拒绝并说明；恢复后全站刷新P0
FR-10-07示例与清空：载入示例工作室（原创虚构数据，见 §2）；清空全部业务数据——保留主理人形象、主题、数据标准与 AI 设置；弹窗明示"清空不等于清除 Key，需到 AI 设置单独清除"两项操作前强制确认；建议先备份的提示常驻P0

2 · 示例数据（原创虚构）

  • 虚构工作室「拾光内容室」（名字原创）：3 个 IP（数码效率 / 家常美食 / 职场成长）、9 个账号（3 IP × 3 平台）、2 个对标账号含 8 条原创虚构拆解作品、6 条覆盖各阶段的内容（含 2 条已回填数据的发布记录）、5 条热点、3 个自定义营销节点。
  • 示例内全部人名/账号名/数据均为编造，不指向任何真实账号。
