PRD-02 · 热点雷达

回答"现在有什么热点、适不适合我的 IP、从哪个角度蹭"。热点手动录入（不做抓取），72 小时黄金窗口提醒，按 IP 人设生成切入角度，一键转入选题池。

1 · 用户故事

  • 刷到热点 → 花 30 秒录入 → 系统告诉我它还剩多少小时、适合哪几个 IP、每个 IP 从什么角度切入。
  • 角度想清楚了 → 一键变成选题池里的一道题，不丢上下文。

2 · 功能需求

编号需求验收标准优先级
FR-02-01热点录入/编辑/删除：标题（必填）、来源、热度（高/中/低）、趋势（升/平/降）、备注保存后立即出现在列表头部并开始倒计时P0
FR-02-02适用 IP 标记：多选当前可见 IP（含「全部 IP 共用」）；列表中每个热点显示 IP 头像排未标记 IP 的热点在单 IP 视图不显示；标记即时保存P0
FR-02-0372 小时窗口：dueAt = 创建时间 + 72h；列表按剩余时间升序；剩余 <24h 标橙；过期置灰折叠到「已过期」区倒计时按分钟刷新；过期不自动删除P0
FR-02-04切入角度：对每个适用 IP，按其赛道与人设生成 3 条角度建议（本地模板引擎；配置 AI 后可一键用 AI 生成增强版）；建议可编辑、可补充不同 IP 的建议互不影响；生成结果保存到热点记录P1
FR-02-05转选题：选择角度后进入选题表单（预填标题=角度句、来源=hot、关联热点 id、五维给默认中间分 3/3/3/3/3），确认后进 PRD-04 选题池转换后热点标记「已转选题」并可跳转查看生成的选题P0
FR-02-06热榜直达：各平台热榜的外部链接集合（新标签打开），纯跳转无抓取链接清单可在设置中自定义增删P1
FR-02-07营销节点：内置一年主要节点（法定假日 + 电商大促 + 节气抽样）并支持自定义节点（名称+日期）；列表显示倒计时天数；指挥板右栏引用（FR-00-03）节点数据随备份走；内置节点可隐藏P1

3 · 规则说明

  • 角度模板引擎（本地）：按「赛道关键词 × 人设语气 × 热点类型（事件/产品/话题/争议）」组合句式生成，输出为建议而非保证；文案模板全部自写。
  • 蹭热点前的三问提示（固定文案，展示在录入表单顶部）：这和我的赛道有关吗 / 我的人设适合说吗 / 72 小时内出得来吗。
  • 本模块不联网抓取任何榜单（NFR-02），外部榜单跳转是唯一出网点之一。
