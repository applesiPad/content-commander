# 内容指挥部 · Content Commander

面向短视频口播创作者的**多 IP / 多账号内容工作台**。纯前端（原生 HTML/CSS/JS），零依赖、零构建、离线可用，数据存本机浏览器。

> 📋 **开发必读**：[PROJECT.md](PROJECT.md) —— 决策记录、进展台账、卡点清单、下次开工指南

## 快速开始

双击打开 [`内容指挥部/index.html`](内容指挥部/index.html) 即可使用（首次进入可选"载入示例工作室"）。

## 功能闭环

热点雷达（**热榜直达/切入角度引擎/节点管理**）→ 对标拆解（**自动分段/结构识别/借选题/套结构**）→ 选题池（五维评分/**雷达画像**/评级线可调/**看板拖拽**）→ 文案工坊（体检/分镜/**封面画幅预览/快照对比**）→ 拍摄与提词（**全屏提词器：速度/字号/镜像/按镜高亮；拍摄日程/开拍清单/景别速查**）→ 发布排期（一稿多发/复制三连/创作者后台直达/**发布确认清单**）→ 数据复盘（**趋势双轴/对比条形/三联筛选**/象限诊断/**周报环比+Word**/**粘贴回填预览**）→ AI 助手（**16 模板完整提示词/双协议/上下文预览/测试连接/结果回填**，可选接入）

## 设置能力（D-04：判断阈值全部可调）

12 项数据标准线（语速/5秒完播线/收藏率线/均播比线/评论率线/爆款倍数/收藏画像比/评级线 S·A·B/封面字数上限/IP 上限）+ 平台管理（默认 9 家：抖音/小红书/视频号/B站/快手/微博/公众号/知乎/百家号，支持自定义追加）。

## 产品边界（合规）

不登录、不授权、不调用任何内容平台接口；不代发、不抓取榜单；发布为"一键准备 + 手动发布 + 回来标记"的辅助闭环。详见 PRD-00 §4 与 NFR-06。
